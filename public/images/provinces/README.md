# Province cover photos

One local copy per province for the homepage "Explore all 25 provinces" cards
and the province pages they open. Serving the covers from this site keeps every
card loading when a third-party host is slow, rate-limits, or blocks hotlinked
requests. Each file is a 1280px-wide JPEG (the only external source, Tatai
Waterfall, is reused at its original 1024px width). Cards crop them for display.
